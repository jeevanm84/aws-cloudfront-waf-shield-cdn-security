# Security policy

This repository contains educational documentation, diagrams, and a Terraform example — it does not run a live service. For the security *design* covered by this repository's content, see [`docs/SECURITY.md`](docs/SECURITY.md).

## Reporting a vulnerability

If you find a security issue in this repository itself — for example, a Terraform example that would provision an insecure default, or a script that mishandles input — please use GitHub's private vulnerability reporting for this repository rather than opening a public issue.

## Scope

- In scope: the Terraform example, the validation script, and any documented commands.
- Out of scope: AWS service vulnerabilities themselves — report those through AWS Security (https://aws.amazon.com/security/vulnerability-reporting/).
